# The Trail: Frontier Challenge 简体中文汉化

《The Trail: Frontier Challenge》简体中文汉化项目。

- 作者：崖上望秋千
- 当前版本：v1.0.0
- 适用平台：Windows 正版

## 项目说明

本项目旨在为游戏提供简体中文本地化支持。

## 安装

正式补丁发布后，请前往仓库的 Releases 页面下载对应版本，并严格按照该版本附带的安装说明操作。

安装前建议：

1. 关闭游戏与 Steam 云同步冲突提示。
2. 通过 Steam 验证游戏文件完整性，确保游戏文件未被其他补丁修改并备份自己的存档以防出现不可预知的错误。

具体安装操作：

将下载的文件解压后将其中的 resources.assets 复制到游戏目录，通常为：..\steam\steamapps\common\The Trail\TheTrail_Data\

如需恢复原版，请在 Steam 中执行：

`库 → The Trail → 属性 → 已安装文件 → 验证游戏文件完整性`
