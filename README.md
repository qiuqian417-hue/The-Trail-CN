# The-Trail-CN
游戏《The Trail: Frontier Challenge》简体中文汉化项目。

作者：崖上望秋千
版本：v1.0.0
适用平台：Windows 正版 (其他版本未经测试)

安装
关闭游戏与 Steam 云同步冲突提示
通过 Steam 验证游戏文件完整性，确保游戏文件未被其他补丁修改，备份自己的存档
将下载的 resources.assets 文件复制到游戏目录，通常为：..\steam\steamapps\common\The Trail\TheTrail_Data\

恢复
在 Steam 中执行：库 → The Trail → 属性 → 已安装文件 → 验证游戏文件完整性
